## 便宜的三个隐藏成本

**计费小时上限 672。** LightNode 的计费页写着 `capped at 672 hours`，一个自然月最多按 672 小时收费，不是 730 小时。按小时买的整月成本有封顶，不会被多收；反过来，长期开着也不会因为“按小时”而更便宜。

**最低充值 $10，支付宝扣港币。** LightNode 开机前要先充值，最低 $10 起。支付宝付款时你付人民币，实际扣的是港币，中间有汇率差，金额不大但确实存在。付款方式官网列了信用卡、PayPal、支付宝、Google Pay。

**余额不退。** LightNode 服务条款原文是 `fees paid to us are non-refundable`，充进去的钱不退。这条对“先充 $10 试试”的人是实打实的风险。

## 华为云和 AWS 为什么算不上便宜

华为云亚太-曼谷买不到轻量服务器，只能买 ECS。最低一台 1 核 2GiB 配 40GiB 硬盘，带宽 1Mbit/s，¥151.02/月。把带宽加到 5Mbit/s 是 ¥294.22，多出 ¥143.20，摊下来约 ¥35.80 / 1Mbps / 月。钱主要花在带宽上，配置本身不是大头。另外，计算器里根本没有流量这一项，别理解成“用多少都不额外收钱”。

AWS 泰国区的情况更绕。区域代码 `ap-southeast-7`，官方名 Asia Pacific (Thailand)，3 个可用区，新账号默认不开，得手动启用。这个区没有 Lightsail，只能用 EC2。按每月 730 小时、20GB 硬盘、1 个公网 IPv4 推算，t3.micro（2vCPU/1GiB）约 $14.07/月，t4g.small（2vCPU/2GiB）约 $19.32/月，都是推算值不是报价。出网流量另算，$0.108/GB，跑 100GB 就再加 $10.80。

两台大厂机器加起来的信息说明一件事：泰国机房低价，是大厂没进来竞争的那部分市场，不是技术或线路有什么特殊优势。

## 大陆访问：271–313ms 意味着什么

萤光云官网自己公布的 2026 年 7 月数据：大陆三网到它曼谷节点的平均延迟，电信 313ms、联通 271ms、移动 296ms，丢包率都是 0.13%。

它的 FAQ 写得很直白：“泰国VPS用的是国际BGP线路，大陆直连可能会出现轻度数据丢失和较高的延迟。”LightNode 那边同样是国际 BGP，下单页提示到中国延迟略高，FAQ 里建议用控制台 VNC 连接来部署，这句话背后的意思你懂的：SSH 传文件会卡。

四家官网都没有写泰国机房有 CN2 或 CN2 GIA。

271ms 是什么体感？打开一个没做 CDN 的页面的首字节时间就够呛，后台操作会有明显停顿。访客主要在大陆的站，泰国机房不该在候选名单里，该看香港和日本。这是判断，不是偏好。

- **访客主要在大陆**：这几家都别选，去香港、日本。
- **只想要一台便宜的亚洲节点做代理、测试、跑脚本**：LightLayer 台湾档 $24.99/年 是这份资料里最低的亚太年付价，5Mbps 带宽够跑轻量任务，别指望它扛流量站。

## 下单前要核的五件事

1. 关机是否计费。按小时计费的服务商，关机后往往仍收硬盘和 IP 的费用，不确认会算错账。
2. 退款退到哪。退到余额和退回原支付渠道是两件事，前者等于钱还在商家手里。
3. 区域要不要先开通。AWS 泰国区新账号默认关闭，不手动启用连机器都开不出来。
4. 能不能装 Windows。萤光云入门档 1 核 2GB 装不了 Windows，要 2 核 4GB 起步；deedeehost 和 21st-thailand 只给 Linux。
5. 支付宝结算币种。LightNode 是付人民币扣港币，汇率差自己承担；thaivps.asia 用支付宝需要把账户币种设成 CNY。

## 常见问题

**泰国 VPS 有 CN2 线路吗？**
这四家官网都没写泰国机房有 CN2 或 CN2 GIA。LightNode 下单页提示 BGP 到中国延迟略高，萤光云 FAQ 说国际 BGP、大陆直连可能丢包。要 CN2 得看香港和日本。

**泰国 VPS 能装 Windows 吗？**
分商家。萤光云要 2 核 4GB 起；deedeehost 只提供三种 Linux 发行版；21st-thailand 明确不提供 Windows VPS。LightNode 有 Windows 选项，用远程桌面连。

**能在泰国 VPS 上跑邮件服务吗？**
deedeehost 封了 SMTP 25 端口，官方建议改用外部邮件服务。其他几家没在公开页面写清楚，得开工单问。

**有没有曼谷机房 VPS 的真实测评数据？**
这四家曼谷机房都没有可用的公开测评数据，跑分、硬盘读写、测速、回程路由全都没有。唯一能拿出来的是萤光云官网自己公布的 2026 年 7 月三网延迟，271–313ms，丢包率 0.13%。想自己判断，就买按小时计费的或者带退款期的，跑一段时间再定。

**泰国机房和新加坡机房怎么选？**
访客集中在泰国，放曼谷。访客分散在东南亚多国，新加坡或香港的连接质量更稳，LightLayer 这两地的年付档分别是 $70 和 $50，比在曼谷按月付还省。
